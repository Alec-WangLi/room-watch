# 隐私说明

> 一句话：**画面处理全部在本机完成**。离开这台机器的，只有你自己配置的推送消息
> 和一个不含画面的存活心跳。

## 本机处理，不经过云端

- 人体检测（YOLOv8n ONNX）、人脸检测（YuNet）、人脸识别（SFace）全部在本机 CPU 上运行；
- 语音播报使用 Windows 自带的 SAPI5，离线合成；
- 没有账号、没有遥测、没有「匿名使用数据」上报；
- 程序启动时不会上传配置、日志或画面。

## 哪些数据会离开机器

只有两类，且都由你显式配置：

1. **推送渠道**：启用哪个渠道，就把事件文字发到哪个渠道；企业微信机器人可以额外
   发送抓拍图片与压缩后的录像。SFace 模板、原始录像文件不会上传到任何项目服务器。
2. **外部心跳**（可选）：guardian 定时请求你填写的心跳 URL（如 healthchecks.io），
   只发一次 HTTP 请求，**不包含画面、人脸或配置**。

如果两者都不配置，程序不会产生任何出站网络请求（自动更新检查除外；
可用 `update.check_interval_hours: 0` 关闭后台检查）。

## 本机存了什么

| 位置 | 内容 | 说明 |
|---|---|---|
| `data/captures/` | 抓拍 JPG、录像 MP4、音轨 WAV | 按日期分目录，受保留天数与容量上限约束 |
| `data/identity/` | 本人 SFace 特征 `owner.npz`、注册照片 `owner.png` | 生物特征，仅本机 |
| `var/db/events.db` | 事件时间、身份标签、是否已通知 | 不含人脸特征 |
| `var/db/outbox.db` | 待投递消息与重试状态 | 可能含事件文字与媒体临时文件路径 |
| `var/logs/` | 运行日志 | 配置里的密钥已脱敏 |
| `config.local.yaml` | 推送凭据、相册密码、心跳 URL | 不入库、升级保留 |

以上目录默认都在安装目录下；卸载时 `data/`、`config.local.yaml` 和 `var/db` 会保留，
需要彻底清除请手动删除。

## 诊断包

`rw diag` 生成的 zip **刻意不收录 `data/`**：不含抓拍、录像、人脸模板。
配置与本地覆盖文件里的密钥只保留末 4 位；日志按尾巴收集。
如果仍然担心，打开 zip 确认后再发送。

## 相册的边界

- 默认只监听 `127.0.0.1`，手机看不到；
- 改为 `0.0.0.0` 时必须设置至少 12 位密码，但传输仍是明文 HTTP；
- 只应在可信局域网使用；公网访问请套 HTTPS 反向代理或 Tailscale。

## 录音

启用录像音轨时，程序通过系统默认麦克风录音，音频只写入本机 mp4（可选保留 WAV）。
音频不会随推送渠道发送；企业微信录像推送会做压缩与转码。

## 数据删除与保留

- `snapshot.keep_days`：按天清理抓拍/录像/音频（0 = 不按天清理）；
- `storage.max_total_gb`：按总量清理，最旧优先，正在写入的文件受保护；
- 设置 → 身份 →「清除模板」会删除本人特征与注册照片；
- 停止监控后删除整个 `data/` 目录即可清除全部媒体与人脸数据。

## 第三方组件与许可

检测模型来自 Ultralytics YOLOv8（AGPL-3.0），人脸模型来自 OpenCV Model Zoo。
第三方来源与许可见 `NOTICE`；本项目整体以 AGPL-3.0 发布。
