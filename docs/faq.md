# 常见问题（FAQ）

> 面向「装完就想让它一直跑」的使用者。开发/构建问题见 `AGENTS.md`。

## 摄像头

**Q：提示打不开摄像头 / 被占用？**
摄像头同一时间只能被一个进程使用。依次检查：

1. 是否有会议软件（腾讯会议、Teams、Zoom）、相机应用或另一份监控在占用；
2. `rw status` 看是否还有监控进程；界面「停止监控」后再点「拍预览图」；
3. Windows 设置 → 隐私和安全性 → 相机 → 确认「允许桌面应用访问相机」已开；
4. `camera.index` 试 0、1、2；网络摄像头检查地址、用户名和密码。

**Q：状态显示在线，但没有新画面？**
`status.json` 里的 `stale` 字段可能来不及更新。以 `rw status` 为准；
它会重新计算「心跳新鲜 + PID 还活着」。仍无画面时看 `var/logs/watcher.log`
与 `var/logs/watcher-fault.log`，再跑 `rw diag`。

**Q：电脑锁屏/睡眠后还会监控吗？**
USB 摄像头只能在**已登录的 Windows 会话**里采集，不能放进 Session 0 的服务。
请保持登录（可以自动登录后锁屏），并把电源计划里的「睡眠」设为「从不」。
注销或休眠会让采集停止，guardian 只能在进程层面重试，救不回被系统挂起的设备。

## 身份识别

**Q：事件表里“人体置信度”有 0.92，为什么身份还是“访客 / 认不出”？**
这两个数不是一回事。“人体置信度”是 YOLO 判断“画面里有一个人”的把握；
身份看的是人脸 SFace 与本人模板的相似度（阈值默认 0.45）。侧脸、低头、
背对镜头时，人形检测依然很确定，但人脸可能找不到或相似度不够。

**Q：我侧脸进门先被当成陌生人，转身后才认出我，照片/录像已经发出去了？**
0.1.20 起，事件触发后会先压住通知 15 秒，并在窗口内每秒重新识别：
确认本人就删除抓拍/录像并撤销未发通知；连续两次明确不像你则立刻放行；
窗口结束仍认不出才按陌生人发送。窗口结束后才认出本人不会再撤回，
因为消息已经发出。

## 推送

**Q：微信收不到告警？**

1. 设置 → 推送 → 「发送测试消息」，或 `rw config --test`，逐渠道确认；
2. 企业微信机器人只能发到**内部群**，不能发外部群；
3. 检查该渠道的「人员事件」开关是否被关掉（critical 告警不受此开关影响）；
4. 看主界面底栏的「待发送 N」与设置页的渠道健康时间；
5. 断网期间事件会进持久化队列，恢复后自动补发，不需要重装。

**Q：为什么建议至少两个渠道？**
单个渠道（尤其是企业微信机器人）可能被限流、改配置或失效。两个渠道同时发，
其中一个坏了另一个仍然送达；界面会提示「只启用一个渠道」。

**Q：为什么「检查更新」说已是最新？**
自动更新只认 GitHub 的**稳定版 Release**。测试版是 prerelease
（tag 形如 `v0.1.17-beta`），`/releases/latest` 不会返回它；测试者请手动下载安装包。

## 相册与手机访问

**Q：手机打不开相册？**
设置 → 相册：把 host 改为 `0.0.0.0` 并设置至少 12 位密码；手机与电脑连同一个
Wi-Fi；首次访问可能需要在 Windows 防火墙里放行。实际端口以
`var/state/gallery.json` 为准（首选端口被占用时会自动回退）。

**Q：能不能走公网？**
相册是明文 HTTP + Basic 认证，只适合局域网。要走公网请在前面套 HTTPS
反向代理或 Tailscale，不要把端口直接暴露到互联网。

## 存储与录像

**Q：录像太占磁盘？**
设置 → 录像：

- `record.max_seconds` / `max_total_seconds` 控制单段与一次在场上限；
- `record.owner_at_computer` 选 `skip` 可在你使用电脑时不录像（默认 `mute` 仍录、只是不推送）；
- `storage.max_total_gb` 与 `snapshot.keep_days` 控制总量与保留天数；
- 「存储与容量预测」会按最近几天的写入速度告诉你还能撑多久。

**Q：为什么我坐在电脑前时录像还在继续？**
默认策略是 `mute`：照录不推送。这是为了不漏掉「你在电脑前时别人进入房间」，
磁盘用容量上限兜底。愿意用存储换隐私/空间的人可以显式改成 `skip`。

## 安装与安全软件

**Q：Windows SmartScreen / 杀毒软件报风险？**
安装包没有代码签名，PyInstaller 打包的程序常被启发式误报。请从本项目
GitHub Releases 下载，并核对随包的 `.sha256`；不放心可以按源码自行构建。

**Q：怎么反馈问题？**
先跑 `rw verify` 确认摄像头与推送，再跑 `rw diag` 生成脱敏诊断包。
诊断包不含抓拍、录像、人脸模板和完整密钥；把 zip 附在问题里即可。

## 运行方式

**Q：必须一直开着界面吗？**
不需要。监控由 guardian 托管在后台运行，关闭界面不影响；开机自启注册的也是
guardian。界面只是观察和操作窗口。

**Q：暂停和停止有什么区别？**
`rw stop` / 界面「停止监控」会写 `paused`，guardian 不会自动拉起，直到你显式
`rw start`。这是「我就是要它停」的语义，避免它自己偷偷恢复。
